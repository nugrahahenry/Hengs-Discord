# Hengs Sticker Set v1

Delapan stiker maskot Hengs dengan latar transparan. Semua file berukuran 320 x 320 PNG dan siap dipakai sebagai emote Discord atau aset stiker WhatsApp.

| File | Ekspresi |
| --- | --- |
| `hengs-sticker-w-thumbs-up.png` | W dengan jempol dan kilau |
| `hengs-sticker-l-sweat-determination.png` | L dengan keringat dan ekspresi fokus |
| `hengs-sticker-gg-handshake.png` | GG dengan salam bersama robot kecil |
| `hengs-sticker-gacor-flame.png` | Aura api untuk momen gacor |
| `hengs-sticker-santuy-sunglasses.png` | Pose santai dengan kacamata |
| `hengs-sticker-mikir-question.png` | Pose berpikir dengan tanda tanya |
| `hengs-sticker-gas-speed.png` | Pose gas dengan garis kecepatan |
| `hengs-sticker-bobo-sleepy.png` | Pose tidur dengan Zzz |

Lembar sumber 4 x 2 disimpan di `assets/_originals/hengs-sticker-sheet-v1.png`. File individual di folder ini menjadi aset produksi agar mudah diunggah satu per satu.
